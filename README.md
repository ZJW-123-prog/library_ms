# 图书馆管理系统 (Library Management System)

## 项目简介

图书馆管理系统是一个基于Django框架开发的Web应用，用于管理图书馆的书籍、用户、借阅和归还流程。系统支持多角色登录（普通用户、管理员），提供完整的书籍管理、借阅申请、审批和归还功能。

## 技术栈

- **后端框架**: Django 5.2.7
- **数据库**: SQLite (开发环境), 支持MySQL/PostgreSQL (生产环境)
- **前端技术**: HTML, CSS, Bootstrap, Django Templates
- **开发工具**: Visual Studio Code, Git, GitHub
- **AI辅助工具**: GitHub Copilot, ChatGPT 4o, Cursor (代码生成、调试、文档编写)

## 功能模块

### 1. 用户管理
- 用户注册与登录
- 用户信息管理
- 角色权限控制（普通用户、管理员）

### 2. 书籍管理
- 书籍信息的增删改查
- 书籍分类管理
- 书籍状态跟踪（可借、已借、预约）
- 书籍搜索与筛选功能

### 3. 借阅管理
- 借阅申请提交
- 借阅审批流程（管理员操作）
- 借阅记录查询
- 借阅期限提醒
- 自动计算逾期费用

### 4. 归还管理
- 归还申请提交
- 归还审批流程（管理员操作）
- 逾期管理
- 归还记录查询

### 5. 管理员功能
- 借阅审批列表
- 归还审批列表
- 系统统计与报表
- 用户权限管理
- 系统日志查看

### 6. 搜索与统计
- 书籍智能搜索
- 借阅数据分析
- 用户行为统计
- 热门书籍推荐

## 环境配置

### 依赖安装

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 数据库配置

在 `settings.py` 中配置数据库连接：

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
```

## 安装和运行

### 初始化项目

```bash
# 生成迁移文件
python manage.py makemigrations

# 执行迁移
python manage.py migrate

# 创建超级用户（管理员）
python manage.py createsuperuser
```

### 启动开发服务器

```bash
python manage.py runserver
```

访问 http://127.0.0.1:8000/ 即可使用系统

## 开发说明

### Git版本控制

- **主分支**: `main` (生产环境)
- **开发分支**: `feat/功能模块名称` (特性开发)
- **提交规范**: 使用语义化提交信息，如 `feat: 添加借阅审批功能`
- **提交频率**: 每个功能模块开发完成后提交，每天至少提交1次

### GitHub团队协作

- **仓库地址**: [GitHub仓库链接]
- **分支策略**: 基于功能的分支开发模式
- **Pull Request**: 功能开发完成后提交PR，至少1人审核
- **Issues管理**: 使用Issues追踪bug和需求
- **文档更新**: 功能变更后及时更新README.md

### AI辅助编程

| 工具 | 使用场景 | 节省时间 | 学习收获 |
|------|----------|----------|----------|
| GitHub Copilot（VS Code 插件） | 自动生成 models.py 五张表代码 | 约 15 min | 学会外键、索引、Meta 语法 |
| ChatGPT 4o | 生成注册/登录视图 + 表单验证 | 约 20 min | 掌握自定义 User 与邮箱双登入 |
| Cursor | 一键生成 Excel 导出、邮件提醒、封面上传 | 约 25 min | 学会 openpyxl、django-email、ImageField |

**总计节省开发时间**: ≈ 60 分钟
**代码准确率**: > 90%（仅做字段微调）
